# Test Project

## Unit Tests
1. Run all unit tests
   ```bash
   npm run test
   ```

2. Run tests with coverage
   ```bash
   npm run test:coverage
   ```

3. Watch mode (optional)
   ```bash
   npm run test:watch
   ```

## Integration Tests
```bash
npm run test:integration
```
