# N_Rawit_server_node
Node MCU , Web Server, Steam, multimedia, communication ,IOT
## สรุปแนวคิดหลัก N_Rawit

---

### จุดเริ่มต้น
ตั้งจากคำถามว่า "ถ้าอินเทอร์เน็ตโลกถูกตัดขาด เราจะทำอย่างไร?" แทนที่จะรอพึ่ง ISP จึงตัดสินใจสร้างเครือข่ายของตัวเอง

---

### หัวใจของระบบ: N_Rawit Box
อุปกรณ์ตัวเดียวทำได้ 5 อย่าง

1. **สตรีม Content** — วิดีโอ เพลง ข่าวสาร ดึงจาก SD Card ในตัว
2. **ขุดเหรียญ Token** — ได้เหรียญเมื่อกระจายข้อมูลให้คนอื่น
3. **กล้องวงจรปิด AI** — ดูบ้านจากระยะไกล
4. **Smart Home** — ควบคุมไฟ รดน้ำต้นไม้
5. **Cloud Storage ส่วนตัว** — เก็บข้อมูลโดยไม่ผ่าน Server ต่างประเทศ

ฮาร์ดแวร์หลักคือ **ESP32-S3-CAM** ราคาประมาณ 260 บาท

---

### โครงสร้างเครือข่าย
แทนที่จะใช้ ISP เครือข่ายสร้างจาก 3 ประเภทโหนด

- **Gold Node** — PC + Router ประสิทธิภาพสูง วางตามร้านกาแฟ
- **Silver Node** — N_Rawit Box ตามบ้าน
- **Mobile Node** — มือถือของผู้ใช้ที่เดินทางพาข้อมูลไปด้วย

โหนดต่างๆ สื่อสารกันผ่าน WiFi Mesh โดยมีแผนที่ 2D ที่สร้างจากค่า RSSI และ GPS ช่วยหาเส้นทางที่ดีที่สุด

---

### ระบบเศรษฐกิจ Token
ออกแบบให้ทุกคนมีแรงจูงใจ

| บทบาท | ได้/เสีย |
|---|---|
| **Host** (มีไฟล์แชร์) | ได้ Token มากที่สุด |
| **Relay** (เป็นทางผ่าน) | ได้ Token น้อยกว่า |
| **Consumer** (ดูอย่างเดียว) | เสีย Token เรื่อยๆ |
| **เดินทาง** (พาข้อมูลไปที่ใหม่) | ได้ Token โบนัส |

Token ซื้อด้วยเงินจริงได้ และป้องกันการโกงด้วย Blockchain แบบเบา (SHA-256 Hash Chain)

---

### กลยุทธ์การตลาดที่น่าสนใจ
- **เครื่องผ่อนตัวเอง** — รับกล่องไปฟรี แล้วให้เครื่องขุด Token จ่ายคืนจนหมด
- **O2O Marketing** — แจ้งเตือนให้ไปดาวน์โหลดที่ร้านกาแฟ เพื่อประหยัด Token และร้านได้ลูกค้า
- **Gamification** — เกมชิงปราสาท WiFi, ล่าสมบัติ, สัตว์เลี้ยงดิจิทัล

20.ในหน้าของ ฟีด
จะโชวว่าในระบบตอนนี้มีอะไรบ้าง
โดยโชวข้อมูลเมต้าดาต้าที่มีขึ้นมา
จะเลือกได้ว่า จะดู
ฟีต แร้งรายวัน รายสัปดาห์ หรือแบบสะสม


21.ผู้ใช้งานจะใช้
ยูสเซอร์อินเทอเฟส แบบโซเชียลเน็ทเวิร์ค
คล้ายๆกับ เฟสบุค หรือติ๊กต๊อก
โดยจะทำการโพส ข้อมูลเข้าไปในระบบ
แล้วมันจะขึ้นไปโชว์บนฟีด
แต่ระบบจะแค่แค่เมต้าดาต้าเท่านั้น
ข้อมูลดาต้าจะยังอยู่ใน sd card ของโหนด 

22.มีระบบโปรไฟลและการติดตาม
เช่นผู้ใช้งานจะมีโปรไฟลของตัวเองเพื่อดู db ของตัวเองได้

23.ผู้ใช้อื่นๆจะกดติมตามเราได้
เมื่อเรามีโพสข้อมูลใหม่ ผู้ติดตามจะเห็น เป็นอันดับต้นๆในฟีด

24.ผู้ใช้งานจะตั้งได้ว่าใครจะเห็นโพสเราบ้าง
เช่น ส่วนตัว เพื่อน ผู้ติดตาม สมาชิก และทุกคน

25.มีระบบสมาชิกที่ ผู้ใช้งานจะเก็บค่าเข้าร่วม เพื่อรับข้อมูลเฉพาะสมาชิก
