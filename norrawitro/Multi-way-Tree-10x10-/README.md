# Multi-way-Tree-10x10-
Level 1: File Type (Base Logic)
เน้นการคัดกรองทางเทคนิคเพื่อเลือกชุดคำสั่งประมวลผล

1.1 Picture (ข้อมูลภาพ/พิกเซล)

1.2 Sound (คลื่นเสียง/ความถี่)

1.3 Logic/Code (ชุดคำสั่ง/เงื่อนไข)

1.4 Text/Data (ตัวอักษร/ตาราง)

1.5 Map/Coordinate (พิกัดภูมิศาสตร์/พื้นที่)

1.6 System Status (ค่าพลังงาน/อุณหภูมิเครื่อง/Log)

1.7 Sensor Raw (ค่าดิบจากระยะ/ความเร่ง/ไจโร)

1.8 Link/Synapse (ไฟล์ดัชนีการเชื่อมโยง)

1.9 User Profile (ข้อมูลสิทธิ์และตัวตนผู้ใช้)

1.10 Misc/Archive (ข้อมูลเบ็ดเตล็ด/ขยะ)

Level 2: Entity Classification (Existence)
แยกประเภทตามการมีตัวตน

2.1 Human (มนุษย์)

2.2 Animal (สัตว์)

2.3 Plant (พืช)

2.4 Inanimate Object (สิ่งของไม่มีชีวิต)

2.5 Digital Asset (ไฟล์ดิจิทัล/ซอฟต์แวร์)

2.6 Environment/Weather (สภาพแวดล้อม/อากาศ)

2.7 Infrastructure (ถนน/อาคาร/สิ่งก่อสร้าง)

2.8 Abstract Concept (กฎหมาย/ทฤษฎี/เวลา)

2.9 Microorganism (จุลินทรีย์/เชื้อโรค)

2.10 Unknown Entity (สิ่งที่ยังระบุไม่ได้)

Level 3: Geometry & Shape (Appearance)
คัดกรองจากรูปทรงที่กล้องจับได้

3.1 Spherical/Round (ทรงกลม/มน)

3.2 Cubic/Square (ทรงเหลี่ยม/ลูกบาศก์)

3.3 Cylindrical (ทรงกระบอก/เส้น)

3.4 Pyramidal/Triangle (ทรงกรวย/สามเหลี่ยม)

3.5 Flat/Plane (แผ่นเรียบ/ผนัง)

3.6 Irregular (รูปทรงอิสระ)

3.7 Fluid/Liquid (ของเหลว/รูปทรงไม่คงที่)

3.8 Hollow (วัตถุมีโพรง/ท่อ)

3.9 Point Cloud (กลุ่มจุด/ฝุ่น/ควัน)

3.10 Symmetrical (รูปทรงสมมาตรพิเศษ)

Level 4: Scale & Dimension (Size)
ระบุระยะและขนาดที่เซ็นเซอร์วัดได้

4.1 Micro (< 1 cm)

4.2 Small (1 - 10 cm)

4.3 Medium (10 - 100 cm)

4.4 Human-Size (1 - 2 meters)

4.5 Large (2 - 10 meters)

4.6 Building-Size (10 - 100 meters)

4.7 Macro (100 m - 1 km)

4.8 Giant (> 1 km)

4.9 Variable Size (สิ่งที่ขยายหรือหดได้)

4.10 Infinite/Undetermined (อวกาศ/ระยะอนันต์)

Level 5: Surface & Texture (Tactile/Visual Detail)
รายละเอียดพื้นผิวเพื่อความปลอดภัยในการเดิน

5.1 Smooth/Polished (เรียบ/ลื่น)

5.2 Rough/Gravel (ขรุขระ/หินกรวด)

5.3 Soft/Yielding (นุ่ม/ยุบตัวได้)

5.4 Fibrous/Hair (เป็นเส้นใย/ขน/พรม)

5.5 Sticky/Viscous (เหนียว/หนืด)

5.6 Hard/Metallic (แข็ง/โลหะ)

5.7 Porous/Sponge (เป็นรูพรุน)

5.8 Patterned/Striped (มีลวดลาย/ตาราง)

5.9 Wet/Slippery (เปียก/ลื่นน้ำ)

5.10 Granular/Sand (เป็นเม็ดเล็กละเอียด)

Level 6: Structural Integrity (Hardness/Durability)
การทดสอบแรงบีบ 0-3 นิวตัน เพื่อความปลอดภัย

6.1 Ultra-Fragile (แตกทันทีที่สัมผัส)

6.2 Elastic (ยืดหยุ่น/คืนรูปได้)

6.3 Plastic/Ductile (ยุบแล้วไม่คืนรูป)

6.4 Brittle (แข็งแต่เปราะ)

6.5 Rigid (แข็งเกร็ง/ไม่ขยับ)

6.6 Tough (เหนียวแน่น/ทนทาน)

6.7 Liquid State (ไม่มีแรงต้านทางโครงสร้าง)

6.8 Gaseous State (สถานะก๊าซ)

6.9 Semi-Solid (กึ่งแข็งกึ่งเหลว/โคลน)

6.10 Indestructible (ในขอบเขตแรง 3N ไม่มีการเปลี่ยนแปลง)

Level 7: Thermal & Energy (Signature)
ข้อมูลอุณหภูมิและการแผ่รังสี

7.1 Freezing (< 0°C)

7.2 Cold (0 - 20°C)

7.3 Ambient (อุณหภูมิห้อง/ปกติ)

7.4 Warm (30 - 45°C เช่น ร่างกายมนุษย์)

7.5 Hot (45 - 100°C)

7.6 Extreme Heat (> 100°C)

7.7 Electric Source (มีกระแสไฟฟ้าไหลผ่าน)

7.8 Magnetic Field (มีแรงดึงดูดแม่เหล็ก)

7.9 Radioactive (มีการแผ่รังสี)

7.10 Light Emitting (เป็นแหล่งกำเนิดแสง)

Level 8: Functional Role (Use Case)
หน้าที่หรือวัตถุประสงค์ของสิ่งนั้น

8.1 Tool (เครื่องมือ/อุปกรณ์ทำงาน)

8.2 Weapon (อาวุธ/สิ่งอันตราย)

8.3 Food/Fuel (อาหาร/พลังงาน)

8.4 Container (ภาชนะ/ที่เก็บของ)

8.5 Communication Device (อุปกรณ์สื่อสาร)

8.6 Furniture (เฟอร์นิเจอร์/เครื่องเรือน)

8.7 Clothing (เครื่องนุ่งห่ม/ป้องกันตัว)

8.8 Waste/Scrap (ขยะ/ของเสีย)

8.9 Part/Component (ชิ้นส่วนประกอบ)

8.10 Instructional (ป้ายบอกทาง/คู่มือ)

Level 9: Temporal & Frequency (History)
ประวัติและการเปลี่ยนแปลงตามเวลา

9.1 Static/Permanent (ถาวร/ไม่ย้ายที่)

9.2 Temporary (ชั่วคราว/เดี๋ยวก็ไป)

9.3 New/Fresh (เพิ่งถูกสร้าง/เพิ่งเจอ)

9.4 Old/Ancient (เก่าแก่/มีมานาน)

9.5 Periodic (ปรากฏตัวเป็นรอบๆ)

9.6 Fast Moving (เคลื่อนที่เร็ว)

9.7 Slow Moving (เคลื่อนที่ช้า)

9.8 Daily Routine (พบเจอได้ทุกวัน)

9.9 Historical Record (เป็นข้อมูลในอดีต)

9.10 Future Plan (แผนการในอนาคต)

Level 10: Relational Synapse (Contextual Link)
จุดเชื่อมโยงไปยัง Data Box อื่น

10.1 Owner/User (ใครเป็นเจ้าของ/ใครใช้)

10.2 Location/Parent (อยู่ที่ไหน/อยู่ในอะไร)

10.3 Dependency (ต้องใช้ร่วมกับอะไร)

10.4 Similarity (คล้ายกับอะไร)

10.5 Opposite (ตรงข้ามกับอะไร)

10.6 Consequence (ถ้าทำสิ่งนี้ จะเกิดอะไร)

10.7 Sub-Component (ประกอบด้วยอะไรบ้าง)

10.8 External Reference (ลิงก์ไปอินเทอร์เน็ต/ฐานข้อมูลภายนอก)

10.9 Emotional Value (ความสำคัญต่อผู้ใช้)

10.10 Final Goal Link (เชื่อมโยงสู่เป้าหมาย P-2)

การใช้งาน: เมื่อ R.H.E.A. มองเห็น "แก้วน้ำ" ที่วางอยู่บนโต๊ะ
ที่อยู่ของข้อมูล (Data Address) อาจจะเป็น: 1.1 -> 2.4 -> 3.3 -> 4.2 -> 5.1 -> 6.4 -> 7.3 -> 8.4 -> 9.1 -> 10.1
